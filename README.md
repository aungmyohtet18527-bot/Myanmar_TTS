# 🎤 Myanmar Voice Studio

A modern Myanmar Text-to-Speech (TTS) web application built with HTML, CSS, and JavaScript.

Convert Myanmar text into speech and download audio as MP3 with a beautiful and responsive user interface.

---

## ✨ Features

- Myanmar Text to Speech
- Audio Playback
- MP3 Download
- Responsive Design
- Modern Glassmorphism UI
- GitHub Pages Compatible
- Lightweight & Fast
